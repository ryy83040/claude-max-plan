## 先纠正一个常见误解：Max 不是“加强版 Claude”

不少人以为 Max 是一个更聪明的新产品。它只是 Claude 订阅体系里的更高档位，靠更大的用量额度区分，并不存在一个单独收费的"Claude Code Max"产品。

具体来说：

- Claude Code（那个能读代码库、改文件、跑命令的终端编程 agent）从 Pro 档起就全量开放，终端、VS Code、JetBrains、桌面应用、网页端都能用。Max 只是让你能跑得更久。
- 各付费档位的模型阵容相同，Max 不会解锁什么“专属大脑”。
- 上下文窗口也一样，都是 20 万 token。Max 给你的是更多次会话，不是更大的单次窗口。

有一个细节值得单独拎出来：虽然模型阵容相同，但 Claude Code 的默认模型不同——Pro 档默认 Sonnet 4.6，Max 档默认 Opus 4.8（推理更强的旗舰型号），当然两边都能手动切换。这是少数“花钱能直接感受到”的差别。

## Claude Max 适合谁：对号入座

前面是产品逻辑，这一节讲人的逻辑。以下几类人，是 Max 真正的服务对象。

**全天挂在 Claude Code 上的开发者。** Anthropic 推出 Max 的原因说得很直白：最重的那批用户——用 Claude Code 干真实生产工作的开发者——常常午饭前就把 5 小时限额用完了。从零搭一个应用、让 agent 连续几个小时自主跑会话，这类任务在 Pro 上很难不中断。

**做大型重构的人。** agent 每次动手前要读几百个文件理解上下文，输入输出都是海量 token，Pro 的额度在这种任务面前消耗极快。

**靠 agent 干批量活的人。** 从大代码库生成文档、给每个类补测试再跑通修复，一轮任务就能吃掉 Pro 一大块日额度。

**同时服务多个客户的人。** 整天在几个项目之间切换，每个项目都要重建上下文，用量是乘法关系。

**跑自动化任务的人。** 这是 2026 年 6 月新变化带出来的一类：非交互用途（Agent SDK、GitHub Actions、定时脚本）现在有独立的月度额度池——Max 5x 每月 $100、Max 20x 每月 $200，不与交互会话抢额度，也不结转。如果你的工作流里后台自动化不少，Max 的实际价值比标价看起来更高。

## 谁不该升级

- 每天打开 Claude 几次，写写改改、问问问题：Pro 足够，不确定的话先用免费版。
- 偶尔用 Claude Code 改点小东西：Pro 本来就含完整的 Claude Code，不用为“偶尔”付五倍的钱。
- 冲着“更强的模型”来的：模型一样，这笔钱花了也买不到。
- 从没撞过限额的人：没见过限额提示，说明你现在就在对的方案上。

## 怎么判断：数两个东西

**第一，撞墙频率。** 经验法则是这样的：Pro 的限额每周实实在在挡住你一次以上，升级就开始回本；一个月才撞一次，别动。

**第二，每天在 Claude 里的小时数。** 少于 2 小时，Pro；2 到 6 小时且经常跑 Claude Code，Max 5x 大概率能值回差价；6 小时以上，或者 5x 的周限额每周都顶到，才轮到考虑 20x。

还有个更直接的算法：如果 Max 每月能帮你省下两小时以上，按任何正常的时薪算，它都已经回本了。

> 升级的正确姿势是“被墙撞疼了再升”，而不是“以防万一先买顶配”。档位之间的差距纯粹是数量，不是质量。

## 限额到底怎么算：5 小时窗口叠每周上限

Claude 的用量是两层限制叠在一起：一个滚动的 5 小时会话窗口，加一个每 7 天重置的周上限，两层都会独立把你拦住。Max 档的周限额还分两个口径：一个覆盖全部模型，另一个专门限 Sonnet。

2025 年 8 月刚引入周限额时，官方给出过一组粗略参考：Pro 大约每周 40–80 小时的 Sonnet 用量；Max 100 大约 140–280 小时 Sonnet，外加 15–35 小时 Opus；Max 200 大约 240–480 小时 Sonnet，外加 24–40 小时 Opus。官方当时说这套限额只会影响不到 5% 的订阅者。注意，这组数字是快照，额度会随算力和模型版本调整——2026 年 5 月 6 日，5 小时窗口的额度就整体翻过一倍。

撞上限之后有三条路：等重置、开启按 API 计价的加量（需要在设置里预存资金，属于主动开启）、或者升档。想看自己当前的额度和重置时间，去 Settings > Usage，或者在 Claude Code 里敲 `/usage`。

## 几个高频问题

**Max 是无限量吗？** 不是。哪怕最贵的 Max 200 也有周上限，只是高得多。"Max"这个名字容易让人误会，它只是“很大”，不是“没有”。

**Pro 撞墙会被完全断掉吗？** 不会。系统会让你选择切到 Haiku 这类轻量模型继续，或者等额度刷新。

**怎么从 Pro 升级？** 在账户设置里操作，不需要重装 Claude Code，同一套登录凭据。有个坑要提前知道：如果环境里设了 `ANTHROPIC_API_KEY`，Claude Code 会无视订阅、直接按 API 计费。升级完先检查这个环境变量。
